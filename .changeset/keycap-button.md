The Button is a key (Keycap): flat, with a small corner (`radius-control`), and its depth in a thicker bottom line (`key-edge`, `key-edge-sm`) that closes when pressed. Labels are in sentence case, not tracked capitals. The primary is a light key rather than green, which now means only "needs you"; danger is a grey key with red words that fills red when armed. A new `icon` prop puts any icon before the label. The Button stories follow the Carbon structure, with a docs page.
