Empty, loading and error states drawn on the horizon (Harry's pick, 6 Nov). Quill `State` has no box: the sentence sits on a groove, loading draws the line across, an error turns it red with a diamond, and offline amber. Its action is now a Keycap button. New `size="page"` for a whole page, and new `StateBoundary`, which shows a State when a part throws while drawing. Common `Progress` is the same line, filled with ink instead of green, and the current step in `Steps` is ink too: green means only "needs you". `Rows` no longer puts `role="alert"` on a list item.
